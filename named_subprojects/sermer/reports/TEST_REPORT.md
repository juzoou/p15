## Исправления

- Автоматический алгоритм включается без явного `--algorithm`.
- Оценка ORDER вычисляется по фактически размещённым фишкам, выводится признак `solved`.
- Одномерная разрешимость и конструктивное решение работают при любом положении пустоты.
- Уже собранное поле возвращает ноль ходов.
- Поддержаны квадратные поля из тестов преподавателя; Python и C++ согласованы.
- Поддержаны упрощённый вход, UTF-8 BOM и Windows-пути с кириллицей.
- Добавлены `--score-only`, параметры до/после путей, проверка выхода до поиска и защита входа от перезаписи.
- Решение каждого алгоритма перепроверяется перед записью.
- В дополнительных алгоритмах добавлены проверки переполнения стоимости; RBFS обрабатывает исчерпанную ветвь.
- Генератор и сборка общие; тесты используют текущий Python и одинаковый исполняемый файл.
